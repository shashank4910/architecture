# Working rules

- Keep explanations short, plain and focused on the current decision. Conserve tokens; avoid repeating context or unnecessary tool output.
- Generate images only for an agreed task. Do not create speculative variants, hidden batches or unused previews.
- Inspect every generated image and make it visible to the user by displaying it, opening it or providing a direct deliverable link.
- Reuse existing images when unchanged. Do not rerender them solely for a comparison or repeat successful checks without a relevant change.
- Do not start bulk generation or expand the number of designs beyond the agreed scope.
